# insurance-claim-severity-prediction



[![CI](https://github.com/njagicollins/insurance-claim-severity-prediction/actions/workflows/ci.yml/badge.svg)](https://github.com/njagicollins/insurance-claim-severity-prediction/actions/workflows/ci.yml)


End-to-end insurance claims analytics project: predicts claim severity (Low/Medium/High) and prolonged settlement risk using SQL, feature engineering, NLP (NLTK, TF-IDF) on adjuster notes, and scikit-learn models (Logistic Regression, Decision Tree, Random Forest, Gradient Boosting). Built on synthetic data
